# Mercado_Libre_HTML

El primer clon solo tiene una estructura muy sencilla con los elementos esenciales: un encabezado, una barra de búsqueda, categorías y un pie de página. Es completamente funcional como una página HTML básica, la version creada por la ia tiene una estructura más organizada, con detalles adicionales como imágenes (logotipo), más categorías

Que se aprendio? La página estática que se puede hacer solo con HTML es muy básica y carece de personalización visual, no se pueden agregar estilos ni comportamientos dinámicos sin CSS o JavaScript.
-Usar una herramienta de IA, como ChatGPT o Copilot, puede ayudar a estructurar mejor el código, sugerir mejoras y agregar detalles adicionales
